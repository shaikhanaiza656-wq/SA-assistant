# Drop your trained "SA" Porcupine keyword file here

This folder is intentionally empty in source control — it is **not** a
fake/placeholder `.ppn` file, because no `.ppn` file for the word "SA" can
honestly be generated by this project. Picovoice trains keyword models on
their own servers; the file only exists after you ask their console to
build one for "SA" specifically.

## One-time setup (free, ~2 minutes)

1. Go to https://console.picovoice.ai and create a free account.
2. Console → **Porcupine** → **Train a wake word** → type `SA` → platform
   **Android** → Train.
3. Download the generated file — it will be named something like
   `SA_en_android_v3_0_0_2026-07-01-utc.ppn`.
4. Copy that exact file into this folder
   (`app/src/main/assets/porcupine/`).
5. In the app's Settings screen:
   - Paste your Picovoice **AccessKey** (shown on your Console dashboard)
     into the "Picovoice AccessKey" field.
   - If you didn't rename the file, the app already looks for
     `porcupine/SA_android.ppn` by default
     ([`WakeWordPreferences.DEFAULT_KEYWORD_ASSET`]) — either rename your
     downloaded file to `SA_android.ppn`, or call
     `WakeWordPreferences.setPorcupineKeywordAsset("porcupine/<your file name>")`
     to point at the exact name Picovoice gave you.

## What happens if you skip this

Nothing breaks. [`PorcupineWakeWordEngine`] fails fast with a clear reason
when the AccessKey/keyword file aren't present yet, and
[`WakeWordListener`] automatically falls back to its existing
SpeechRecognizer-loop spotting instead — wake-word detection keeps
working, it's just the always-on, lower-battery Porcupine path that's
unavailable until you do the steps above.
